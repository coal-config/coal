Notes for the reviewer:

 * coal is a Cargo workspace with two crates (coal, coal-lsp). dh-cargo's
   buildsystem builds a single crate, so debian/rules drives
   /usr/share/cargo/bin/cargo directly, the way dh-cargo does internally,
   and runs dh-cargo-built-using for both binaries.
 * All crates come from the archive; there is no vendoring. The upstream
   Cargo.lock is removed before the build (debian/source/options ignores
   that) so cargo resolves against the librust-*-dev packages.
 * The full test suite runs at build time. autopkgtests run the upstream
   build fixtures and the shipped example against the installed coal, and
   do an initialize / diagnostics / shutdown round trip with coal-lsp.
 * lintian (pedantic) is clean apart from an override for
   embedded-library libyaml, which comes from rust-unsafe-libyaml
   through serde_yaml and is recorded in Static-Built-Using.
 * I am the upstream author.
